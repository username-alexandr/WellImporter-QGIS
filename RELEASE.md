# Well Importer 2.0.6 — исторический snapshot

Эта ветка сохраняет состояние стабильной версии **2.0.6** непосредственно перед переходом проекта на 2.1.0.

Ключевые особенности версии:

- единое логическое поле `Номер скважины` для точек и площадных кругов;
- критическое исправление переноса номера скважины в площадной круг;
- отдельное исправление точек бурения и площадных кругов;
- создание пользовательских профилей через `+ Добавить профиль…`;
- Центр управления, контроль качества, поиск, карточки скважин, архив и базовая подготовка проекта для выезда.

Ветка предназначена только для просмотра, сравнения и восстановления исторического исходного кода. **Не сливать её в `main`.**

Исходный стабильный коммит до создания архивной пометки: `816f3cc823cf68274a5972dfe073a6bc08cbc1ad`.
