Актуальный адрес рабочего репозитория: `https://github.com/username-alexandr/WellImporter-QGIS`.

## Дополнительная проверка README

Для архивных веток 2.1.0, 2.2.0, 2.2.1, 2.2.2 и 2.2.3 значение «Текущая версия» в README совпадает с версией соответствующего архивного снимка.

В `archive/v2.2.0` обнаружены исторические опечатки текста README (`точка/угол`, `Пропосные возможности` и повреждённая строка импорта). Они не являются ошибкой номера версии и оставлены без изменения, чтобы архивная ветка сохраняла состояние исходного релиза.

## Найденная активная несогласованность

В `archive/README.md` ветки main до 2.2.4 одновременно упоминались текущая стабильная 2.2.3 и ошибочная «актуальная версия 2.0.6». Файл исправлен: после выпуска он указывает текущую стабильную 2.2.4 и объясняет правило исторических веток.

## Старый GitHub URL

Часть исторических веток содержит `repository=https://github.com/SashaRai/WellImporter-QGIS`, потому что это значение было частью их исходного metadata.txt в момент создания снимка. Исторические ветки намеренно не переписываются ради сохранения архивной целостности.

В активной версии 2.2.4, README, metadata.txt, CI и текущих документах используется новый адрес `https://github.com/username-alexandr/WellImporter-QGIS`.
