# Well Importer 2.2.4

Patch-релиз исправляет работу с земельными участками в проектах, где участки разделены на несколько слоёв (например, государственные участки, земельный фонд и другие категории), но объединены в одну группу QGIS.

## Изменено

- пользователь выбирает одну группу земельных участков в Центре управления;
- выбор сохраняется в настройках Well Importer и в профиле;
- все полигональные слои внутри выбранной группы и вложенных подгрупп анализируются рекурсивно;
- для каждой скважины отдельно определяется конкретный пересекающий её участок;
- кадастровое поле определяется отдельно для каждого слоя;
- назначение участка берётся из подходящего поля (`Назначение`, `Категория`, `Вид использования`, `Собственность`, `Владелец`, `Тип` и совместимые варианты), а при его отсутствии — из названия слоя;
- в слой скважин записываются `Земельный участок`, `Кадастровый номер`, `Назначение участка` и `Источник участка`;
- если скважина попадает одновременно в несколько полигонов, автоматический выбор запрещён и создаётся конфликт для проверки;
- режим «только выделенные скважины» теперь требует реального выделения и не переходит незаметно к обработке всего слоя;
- мастер выезда использует временный объединённый `MultiPolygon`-слой всех участков выбранной группы, поэтому выбор территории работает сразу по нескольким исходным слоям.

## Совместимость с предыдущими исправлениями

Активный runtime-интерфейс 2.2.4 явно подключает:

- пространственную достройку отсутствующих площадных кругов из 2.2.2;
- устойчивый CSV/TXT-декодер из 2.2.3.

Это исключает ситуацию, когда исправляющий класс присутствует в исходниках, но не используется фактической цепочкой `classFactory` QGIS.
