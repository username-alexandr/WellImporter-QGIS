# Well Importer 2.2.3

Patch-релиз исправляет импорт CSV/TXT, при котором файлы UTF-16 без BOM могли ошибочно читаться как UTF-8 и приводить к ошибке `line contains NUL`.

## Исправлено

- распознавание UTF-16 LE/BE без BOM до попытки обычного UTF-8;
- безопасное удаление остаточных технических NUL перед `csv.reader`;
- выбор между Windows-1251 и CP866 по правдоподобию русского текста;
- сохранена поддержка UTF-8, UTF-8 BOM, UTF-16 с BOM, Windows-1251 и CP866.

## Проверка

Добавлены регрессионные тесты для всех перечисленных кодировок и отдельный тест, воспроизводящий исходную ошибку `line contains NUL`.
