# Well Importer 2.1.0

## Назначение обновления

Версия 2.1.0 переводит Well Importer от набора отдельных операций к единому рабочему процессу контроля, исправления, полевой подготовки и обратной синхронизации проекта.

## Контроль и исправление проекта

- Все отдельные кнопки аудита заменены одной командой `Полный аудит проекта`.
- Добавлен пошаговый `Мастер исправления ошибок`.
- Результат аудита отображается в интерактивном списке с фильтрацией по серьёзности, категории и поиском по номеру/описанию.
- По выбранной ошибке можно перейти к объекту на карте; добавлена последовательная навигация `Предыдущая ошибка / Следующая ошибка`.
- Добавлено явное автоматическое создание отсутствующих площадных кругов для существующих точек бурения.
- Добавлен отдельный контроль `1 точка = 1 круг` и CSV-отчёт по нарушениям.
- Геометрически связанная точка и круг с разными заполненными номерами считаются критической ошибкой.
- Заполненный номер скважины должен состоять только из ASCII-цифр `0–9`; ведущие нули допускаются.

## Земельные участки и кадастр

- Выбор слоя участков и полей выполняется автоматически по имени слоя, физическим именам полей и псевдонимам.
- Ручной выбор слоя/поля в Центре управления удалён.
- Поле земельного участка записывается в `WI_PARCEL` с псевдонимом `Земельный участок`.
- Кадастровый номер автоматически записывается в `WI_CAD` с псевдонимом `Кадастровый номер`.
- При нескольких пересекающихся полигонах используется детерминированный выбор ближайшего по центроиду участка.

## Статистика

Добавлена интерактивная панель статистики по:

- годам;
- земельным участкам;
- состояниям;
- партиям импорта.

Поле `Состояние` создаётся автоматически. Допустимые значения: `Пробурена` и `Не заполнено`; новые импортированные скважины получают значение `Пробурена`. Нажатие на столбец диаграммы выделяет соответствующие объекты и приближает карту.

## Подготовка к выезду

Мастер выезда перестроен в последовательность:

`анализ проекта → рекомендации → выбор территории → упаковка`.

Поддерживается:

- выезд со всеми объектами;
- уже выделенные скважины;
- один или несколько выбранных земельных участков с автоматическим выбором скважин внутри;
- выделение области скважин рамкой на карте;
- автоматическое заполнение земельных участков и кадастровых номеров перед упаковкой.

## Фоновые карты и офлайн-работа

Добавлен каталог:

- OpenStreetMap;
- Esri World Imagery;
- OpenTopoMap.

Есть избранное, переключение фоновой карты одной командой и проверка доступности источника. Массовый офлайн-кэш публичного источника по умолчанию отключён и включается только после подтверждения пользователем наличия разрешения/лицензии на такой способ использования. Разрешённый кэш создаётся в MBTiles и добавляется в выездной проект как нижний фоновый слой.

## Проверки перед упаковкой

Перед созданием пакета проверяются:

- доступность интернет-слоёв проекта;
- существование обнаруженных локальных внешних файлов;
- базовая готовность рабочих слоёв и проекта.

Отсутствующий внешний файл считается критической проблемой и блокирует упаковку.

## Единый ZIP-пакет и обратная синхронизация

Выездной комплект формируется одним ZIP-архивом. В него включаются рабочий GeoPackage, выездной QGIS-проект, памятка, результат preflight-проверки, данные baseline для синхронизации, каталог фоновых карт, разрешённый MBTiles-кэш при его наличии и интерактивная веб-карта.

После выезда пакет можно импортировать обратно. Сравнение выполняется по схеме `исходный baseline / офисная версия / выездная версия`. Пользователю показываются только объекты, изменённые на выезде. Одновременное изменение объекта в офисе и на выезде отмечается конфликтом; конфликтные записи по умолчанию не принимаются автоматически. Изменения можно подтверждать по одному или все сразу.

## HTML-карты

Добавлены два автономных HTML-экспорта:

- веб-карта в составе выездного пакета;
- отдельная HTML-карта для передачи руководству без установки QGIS.

Карта для руководства поддерживает поиск скважины по номеру, фильтры по году и земельному участку, всплывающие карточки и печать выбранной прямоугольной области.

## Полный рабочий цикл

Добавлена команда `Полный рабочий цикл`, объединяющая:

`импорт → предпросмотр → дубли → создание точек/кругов → полный аудит → земельные участки/кадастр → исправление → повторный аудит → сохранение QGIS-проекта → отчёт → резервная копия`.

Перед запуском полный цикл запрещает наличие уже открытых edit-сессий рабочих слоёв, чтобы автоматические операции не зафиксировали посторонние несохранённые изменения. Итоговый отчёт сохраняется в JSON и CSV, а резервная копия — в ZIP вместе с QGIS-проектом и обнаруженными локальными ресурсами.

## Дополнительные исправления перед выпуском

- Исправлена сортировка рекомендаций мастера выезда по шкале `Severity.ORDER`.
- Фоновый XYZ-слой добавляется вниз дерева слоёв, чтобы не перекрывать рабочие векторные слои.
- Исправлено извлечение URL из provider source при проверке интернет-слоёв.
- Офлайн-MBTiles при наличии добавляется непосредственно в выездной QGIS-проект.

## Проверка

Код версии 2.1.0 проходит статическую компиляцию Python-модулей и автоматические проверки структуры ветки. Полноценный запуск QGIS GUI, провайдеров данных, Processing и реальных проектов должен дополнительно подтверждаться в установленном QGIS 3.28+ перед использованием версии как производственной.
