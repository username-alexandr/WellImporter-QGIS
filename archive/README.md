# Архив предыдущих версий Well Importer

Этот раздел предназначен для хранения исторических версий Well Importer до текущей стабильной версии **2.0.6**.

## Текущее состояние

Во время проверки после переноса архива в GitHub обнаружено, что единый бинарный `tar.xz` был передан через интеграцию не полностью. Поэтому повреждённый файл удалён из стабильной ветки и **не считается корректным архивом версий**.

Локально сохранён и проверен полный исторический набор исходников для 25 версий:

`1.0.0`, `1.1.0`, `1.2.0`, `1.3.0`, `1.4.0`, `1.4.1`, `1.4.2`, `1.4.3`, `1.4.4`, `1.5.0`, `1.5.1`, `1.5.2`, `1.5.3`, `1.5.4`, `1.5.5`, `1.5.6`, `1.6.0`, `1.7.0`, `1.8.0`, `2.0.0`, `2.0.1`, `2.0.2`, `2.0.3`, `2.0.4`, `2.0.5`.

Они будут переноситься в GitHub как отдельные исторические snapshots/ветки, чтобы каждую версию можно было просматривать и сравнивать как обычный исходный код, а не только скачивать одним архивом.

## Исторические ветки

Ветки вида `archive/vX.Y.Z` являются снимками старых версий и **не должны сливаться в `main`**.

GitHub автоматически показывает кнопку `Compare & pull request` после недавнего push в такую ветку. Это нормальное поведение интерфейса и не означает, что старую версию нужно объединять с текущей.

Например, слияние `archive/v1.0.0` в `main` фактически удалило бы большую часть возможностей версии 2.0.6 и вернуло бы исходники к состоянию 1.0.0.

## Стабильная версия

Актуальный код версии **2.0.6** находится в корневом каталоге `WellImporter/` ветки `main`.
