# Архив предыдущих версий Well Importer

Здесь хранится полный исторический snapshot исходного кода Well Importer до текущей стабильной версии 2.0.6.

## Архив исходников

Файл `WellImporter_source_history_1.0.0_to_2.0.5.tar.xz` содержит исходные каталоги `WellImporter/` для **25 исторических версий**:

`1.0.0`, `1.1.0`, `1.2.0`, `1.3.0`, `1.4.0`, `1.4.1`, `1.4.2`, `1.4.3`, `1.4.4`, `1.5.0`, `1.5.1`, `1.5.2`, `1.5.3`, `1.5.4`, `1.5.5`, `1.5.6`, `1.6.0`, `1.7.0`, `1.8.0`, `2.0.0`, `2.0.1`, `2.0.2`, `2.0.3`, `2.0.4`, `2.0.5`.

Внутри архива каждая версия размещена отдельно:

```text
WellImporter_history_1.0.0_to_2.0.5/
  1.0.0/WellImporter/
  1.1.0/WellImporter/
  ...
  2.0.5/WellImporter/
```

Текущая стабильная версия **2.0.6** не дублируется внутри исторического архива: её исходный код находится в корневом каталоге `WellImporter/` ветки `main`.

## Исторические ветки

Ветки вида `archive/vX.Y.Z` являются историческими снимками и **не должны сливаться в `main`**. GitHub может временно показывать для них кнопку `Compare & pull request` после недавнего push — это не означает, что такая ветка должна быть объединена с текущей стабильной версией.
