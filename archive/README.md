# Архив предыдущих версий Well Importer

Этот раздел описывает исторические версии Well Importer, предшествующие текущей стабильной версии **2.2.4**.

## Исторические ветки

Ветки вида `archive/vX.Y.Z` являются снимками конкретных старых версий. Указанная внутри них версия должна совпадать с именем архивной ветки и намеренно не обновляется до текущей версии плагина.

Архивные ветки **не должны сливаться в `main`**.

## Стабильная версия

Актуальный рабочий код версии **2.2.4** находится в корневом каталоге `WellImporter/` ветки `main` после выпуска соответствующего обновления.

Актуальный репозиторий: `https://github.com/username-alexandr/WellImporter-QGIS`.
