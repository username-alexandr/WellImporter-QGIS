# Архив предыдущих версий Well Importer

В этой папке хранится архив исторических сборок плагина до текущей стабильной версии.

## Что находится в архиве

Файл `WellImporter_previous_versions_1.0.0_to_2.0.5.zip` содержит **25 предыдущих версий** Well Importer — от `1.0.0` до `2.0.5`.

Каждая версия внутри архива лежит в отдельной папке. Для версий, где сохранился отчёт статической проверки, отчёт добавлен рядом с ZIP-сборкой.

Текущая стабильная версия **2.0.6** не дублируется в архиве: её полный исходный код находится непосредственно в `main`, в каталоге `WellImporter/`.

## Важное замечание о 1.4.1

Архив `WellImporter_v1_4_1_fixed_structure.zip` исторически содержит в `metadata.txt` значение `version=1.4.0`, хотя по хронологии и имени сборки это исправление версии **1.4.1**. В архиве файл сохранён без изменения, чтобы не переписывать исторический исходник.
