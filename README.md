# Well Importer for QGIS

Закрытый репозиторий исходного кода плагина **Well Importer** для QGIS.

Плагин предназначен для импорта и управления скважинами и площадными кругами: импорт координат из буфера обмена и файлов, построение кругов заданной площади, контроль качества, поиск дублей, история импортов, исправление объектов, работа с земельными участками, подготовка выездных проектов и профили настроек.

## Текущая версия

**2.0.6**

## Основные возможности

- импорт `X | Y | Номер скважины` из Excel/CSV/TXT и буфера обмена;
- поддержка DD, DMS и проектных координат;
- создание точек бурения и площадных кругов;
- нормативная площадь круга по умолчанию — 33 га;
- единое поле `Номер скважины` для точек и кругов;
- интеллектуальный поиск дублей;
- предпросмотр и проверка подозрительных координат;
- история партий и отмена последнего импорта;
- контроль площади и центрирования кругов;
- отдельное исправление точек и площадных кругов;
- архивирование старых импортов;
- подготовка GeoPackage/QGIS-проекта для выезда;
- земельные участки и кадастровые номера;
- поиск скважины и карточка объекта;
- профили настроек.

## Структура

Исходный код текущей стабильной версии QGIS-плагина находится в каталоге [`WellImporter/`](WellImporter/).

Предыдущие версии **1.0.0–2.0.5** сохранены в [`archive/releases/`](archive/releases/) как исторический архив исходных ZIP-сборок. Внутри архива находится `MANIFEST.txt` с контрольными SHA-256 и кратким описанием каждого обновления.

## Правила разработки

- `main` содержит стабильную рабочую версию.
- Крупные функции и критические исправления оформляются отдельными коммитами с понятным сообщением.
- Для крупных изменений рекомендуется отдельная ветка и Pull Request.
- Сложная логика сопровождается docstring и комментариями, объясняющими назначение, ограничения QGIS и причины нетривиальных решений.
- Очевидные строки не комментируются, чтобы код оставался читаемым.
- Крупные обновления и критические исправления заносятся в [`CHANGELOG.md`](CHANGELOG.md).
- Подробные правила описаны в [`DEVELOPMENT.md`](DEVELOPMENT.md).
