# Well Importer for QGIS

Плагин предназначен для импорта и управления скважинами и площадными кругами: импорт координат, полный аудит проекта, исправление объектов, контроль связей точка/круг, земельные участки и кадастровые номера, статистика, подготовка выездных пакетов, обратная синхронизация и автономные HTML-карты.

## Текущая версия

**2.1.0**

## Основные возможности

- импорт `X | Y | Номер скважины` из Excel/CSV/TXT и буфера обмена;
- поддержка DD, DMS и проектных координат;
- создание точек бурения и площадных кругов 33 га;
- единое поле `Номер скважины` для точек и кругов;
- интеллектуальный поиск дублей и предпросмотр координат;
- полный аудит проекта одной кнопкой;
- мастер исправления ошибок;
- интерактивный список ошибок с переходом к объекту и режимом `Предыдущая / Следующая ошибка`;
- автоматическое создание отсутствующих кругов;
- контроль `1 точка = 1 круг` и отдельный отчёт по нарушениям;
- критический контроль несовпадения номера между точкой и кругом;
- проверка номера скважины: допустимы только цифры `0–9`;
- автоматическое определение земельного участка и кадастрового номера;
- поле `Состояние` со значениями `Пробурена` и `Не заполнено`;
- интерактивная статистика по годам, участкам, состояниям и партиям;
- история партий и отмена последнего импорта;
- архивирование старых импортов;
- мастер подготовки к выезду: анализ → рекомендации → территория → упаковка;
- выбор территории по скважинам или одному/нескольким земельным участкам;
- каталог фоновых карт: OpenStreetMap, Esri World Imagery и OpenTopoMap, избранное и быстрое переключение;
- разрешённый пользователем офлайн-кэш фоновой карты в MBTiles;
- проверка интернет-слоёв и внешних файлов проекта перед выездом;
- единый ZIP-пакет для выезда с GeoPackage, QGIS-проектом, веб-картой и данными синхронизации;
- обратная синхронизация офисной и выездной версий с показом только изменённых объектов и контролем конфликтов;
- автономная HTML-карта для руководства: поиск, фильтры, карточки и печать выбранной области;
- режим `Полный рабочий цикл`: импорт → контроль → участки/кадастр → исправление → сохранение → отчёт → резервная копия;
- профили настроек, поиск скважин и карточки объектов.

## Структура

Исходный код QGIS-плагина находится в каталоге [`WellImporter/`](WellImporter/).

## Правила разработки

- `main` содержит стабильную рабочую версию.
- Крупные функции и критические исправления оформляются отдельными коммитами.
- Сложная логика сопровождается docstring и комментариями, объясняющими назначение, ограничения QGIS и причины нетривиальных решений.
- Очевидные строки не комментируются, чтобы код оставался читаемым.
- Крупные обновления и критические исправления заносятся в [`CHANGELOG.md`](CHANGELOG.md).
- Подробные правила описаны в [`DEVELOPMENT.md`](DEVELOPMENT.md).
